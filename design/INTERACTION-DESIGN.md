# Paseo Deck：Tab 交互方案

根据用户提供的 Paseo 原生界面，沿用宿主字体、颜色、图标和内容渲染。目标是减少附加界面，让 Agent 的来源清楚可辨，并将导入与新建放到使用位置附近。

[可交互预览](tab-interaction.html) 使用示例数据，不连接真实 Agent。最终实装截图与验收见 [TABS-RESULTS.md](../TABS-RESULTS.md)。

## 工作区结构

每个分屏有一行 Tab，Tab 下是原生 Agent / 终端 / 文件。一个分屏可以持有多个 Tab；同时只显示当前 Tab。原来单资源窗口自动迁移为单 Tab 分屏，保留 ID、历史、文件状态和布局比例。

取消整个分屏的蓝色选中描边、卡片边框和单独标题栏。当前 Tab 只用宿主的中性底色与文字明暗区分，键盘焦点保留中性可见提示。Tab 栏桌面 32px、窄屏 36px；删除原来的独立工具栏，比原版组合减少 20px。

Agent / 新建 Agent Tab 使用来源 workspace 在 Paseo 侧边栏中的项目图标。无自定义图标时使用宿主原有的字母和颜色回退。标题只保留 Agent 名称；悬停和无障碍名称提供完整名称与来源 workspace。终端和文件使用原生资源图标，来源放在提示中。

## Tab 操作

- 点击切换，当前 Tab 保持可见；过长标题省略，Tab 过多时横向滚动。
- 关闭按钮在当前 Tab、悬停或键盘聚焦时显示，预留位置避免抖动。关闭后切换到相邻 Tab；未保存文件继续走原生确认。
- 关闭最后一个 Tab 后保留空分屏和 `＋`，可继续添加资源。
- `＋` 位于 Tab 列表之后。右侧仅保留放大 / 还原与 `···`。
- `···` 放置新增分屏、当前 Tab 移至新分屏、切换左右 / 上下排列、均分、返回来源 workspace、移除此分屏等低频操作。

## 统一添加面板

默认采用贴着 `＋` 的轻量浮层，宽约 360px，靠边时避让；点击外部或 Esc 关闭。窄屏仍使用同一浮层，适应可用宽度并限制高度，列表内部滚动。不再显示横向 workspace 按钮墙或大标题。

面板包含搜索框、来源 workspace 筛选、一个“新建 Agent”入口和已有 Agent 列表。列表将运行与启动中的 Agent 单独置顶到“正在运行”一栏，每行有“运行中 / 启动中”文字徽标；Tab 同步显示运行指示，结束后自动移除。其余 Agent 显示在“最近会话”。列表每行显示 workspace 图标、Agent 标题、来源与状态。搜索覆盖 Agent 名称与 workspace；空结果提供更换关键词或新建入口。

- **导入已有 Agent**：`＋ → 搜索 / 筛选 → 点击 Agent`。添加至当前分屏并激活；已打开的 Agent 聚焦原 Tab，保持同一会话 ID。
- **新建 Agent**：`＋ → 新建 Agent → 选择 workspace`。打开带来源图标的新建 Tab，随后沿用原生模型选择与 Composer；资源实际创建时机不变。
- **终端 / 文件**：搜索框下方保留轻量分类 Tab，复用来源选择，再显示对应资源或路径操作。
- **新增分屏**：面板底部切换“当前分屏 / 新分屏”，或从 `··· → 新增分屏` 进入同一选择器。选定资源后才新增分屏，取消不留下空窗口。

键盘打开后聚焦搜索；上下键选择结果，Enter 打开，Esc 返回；错误在当前面板内显示，保留输入与筛选。

## 状态与性能

保留原生 Tab 的稳定身份、Composer 草稿、终端进程和编辑器状态。未访问的 Tab 延迟挂载；访问后切换不卸载内容，非当前 Tab 停止可见时间线登记与活跃呈现。关闭 Tab 释放编辑会话缓存和订阅。

最多显示 8 个分屏，资源 Tab 数量不限；超过分屏上限时使用 Paseo 原生 Toast 提示。资源目录仅在添加面板打开时定时刷新；运行状态使用单个可释放的元数据订阅，离开页面释放，不额外订阅 Agent 时间线。图标查询独立于拖动渲染，并限于当前资源或选择器使用的项目。已有 v1 布局迁移为 v2，迁移前保留本地备份；防抖持久化和退出补写继续生效。

验收覆盖多 Tab 切换 / 关闭 / 移动、导入去重、workspace 图标、旧布局迁移、未保存关闭、快捷键、窄屏 / 主题，以及 4 / 8 资源的拖动和后台订阅。
